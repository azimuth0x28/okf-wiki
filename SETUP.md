# Setup

Setup documentation lives in **[docs/installation.md](docs/installation.md)**.

Quick version:

```bash
git clone https://github.com/Ar9av/obsidian-wiki.git okf-wiki
cd okf-wiki
bash setup.sh
```

Then open the project in your agent and say **"set up my bundle"**.
